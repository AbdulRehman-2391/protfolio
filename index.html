AETHER-NIDS — AI Network Intrusion Detection

A machine learning-based Network Intrusion Detection System that classifies network traffic and detects malicious patterns in real time. Trained on NSL-KDD & CICIDS-2017 with Random Forest, XGBoost, and stacked ensemble models. Features SHAP explainability and a live React threat dashboard.

Python XGBoost Random Forest FastAPI React SHAP CICIDS-2017
Live Demo Details

DrowsyGuard — Driver Drowsiness Detection

Real-time computer vision system monitoring drivers via webcam. Uses MediaPipe FaceMesh (468 landmarks), Eye Aspect Ratio (EAR), and Mouth Aspect Ratio (MAR) for drowsiness and yawning detection. Triggers audio-visual alerts to prevent road accidents.

Python MediaPipe OpenCV EAR Algorithm WebRTC Computer Vision
Live Demo Details
🏥

Doc AI — Intelligent Medical Document Assistant

AI-powered medical document processor that summarizes reports, explains prescriptions, flags abnormal lab values, and answers medical questions in English and Urdu. Built with LLM + OCR pipeline for Pakistani healthcare users.

Python LangChain Tesseract OCR FastAPI React LLM Bilingual NLP
Live Demo Details

Map AI — AI-Powered 3D Model Designer

Web app that transforms text prompts and reference images into interactive 3D models rendered in-browser. Built with Three.js WebGL viewer, supports OBJ & GLTF export for use in Blender, Unity, and Unreal Engine.

Three.js WebGL JavaScript React 3D Generation API OBJ GLTF
